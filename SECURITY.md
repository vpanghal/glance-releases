# Security policy

Do not report vulnerabilities or include sensitive logs, credentials, tenant
data, or personal information in a public issue.

Use the repository's private vulnerability reporting form:

<https://github.com/vpanghal/glance-releases/security/advisories/new>

Include the Glance version, macOS version, reproduction steps, expected and
observed behavior, and whether the issue requires opening an untrusted file or
link. Release binaries are unsigned and installed manually; always verify the
published SHA-256 checksum before installation.
